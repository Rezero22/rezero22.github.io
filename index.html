📖 What Is halo-ce-vita?

halo-ce-vita is a community-made port of the classic first-person shooter Halo: Combat Evolved built specifically for the PlayStation Vita handheld console. It is a "decomp port," which simply means the original game logic was carefully rebuilt so it can run on different hardware — in this case, Sony's handheld.

Instead of squeezing the game into an emulator, this project runs the game directly on the device. The result is a version of Halo that feels like it was made for the Vita: the original campaign, the familiar weapons, the same enemies, and the classic soundtrack, all on a screen you can hold in your hands.

You do not need to be a programmer to use this. You only need to download the files, copy them to your console, and launch the game. This page walks you through it in plain language, one step at a time.

🛠️ Troubleshooting

The game closes as soon as I open it. This almost always means a file is missing or the game data is in the wrong folder. Recheck the release notes and make sure every file listed was copied across.

The screen is black but the console is on. Try holding the power button to force a restart, then launch the game again. If it keeps happening, delete the copied files and start the transfer fresh — a partial copy can cause this.

My computer does not show the Vita. Unplug the cable, plug it back in, and make sure you selected the file transfer option on the Vita's screen. Try a different USB port, and avoid USB hubs if you can.

It runs slowly. Close the game, free up some space on the memory card, and make sure no other applications are open in the background. Performance also tends to improve with newer releases, so check the releases page for an update.

There is no sound. Confirm that the audio files from your own game data were copied into the correct folder. The application expects them to be there.

Something else is wrong. The releases page is the best place to look for a fix — the release notes often describe known issues and what to do about them.
